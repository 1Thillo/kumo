Bibliothek – Modus „Pro Bildschirm“: Auswahl beim Anwenden, Import läuft, Hinweis

Setup 5 – Kumo läuft (von 4A oder 4B aus)

„Kumo öffnen“ bittet die laufende Engine über die Pipe, die Systemsteuerung zu öffnen. Das klappt, weil die Engine der vertrauenswürdige Prozess aus „Programme“ ist.

Deinstallieren (440 × 260, aus Einstellungen › Apps)

Standard ist: Daten behalten, damit eine Neuinstallation nahtlos ist. Das ursprüngliche Windows-Hintergrundbild wird wiederhergestellt, bevor Kumo endet.
